# 《Home Defense War》游戏设计文档（GDD）

> 版本：V1.7｜更新日期：2026-08-15｜状态：正式版

## 1. 游戏概述

### 1.1 基本信息

| 项目 | 内容 |
|---|---|
| 游戏名称 | Home Defense War / 家园保卫战 |
| 游戏类型 | 3D 米哈游风像素塔防（单机网页） |
| 平台 | PC 浏览器 / 移动端浏览器 |
| 技术栈 | Three.js r160 + 原生 JavaScript + 原生 CSS |
| 目标用户 | 18-35 岁塔防玩家、二次元/米哈游风爱好者 |
| 单局时长 | 15-25 分钟 |

### 1.2 核心体验

玩家扮演家园指挥官，在固定棋盘地图上自由建造防御塔、操控英雄、使用局内道具与技能，阻止三章共 8 关的怪物潮水进攻基地水晶。核心乐趣是“有限资源下的布局决策 + 即时技能释放 + 局外成长反馈”。

## 2. 设计支柱

1. **自由策略**：全图可建造（道路/基地/装饰除外），点击塔显示射程，布局自由度高于固定塔位。
2. **双轨成长**：局内金币决定单局强度，局外金币/体力/商店/英雄等级构成长期成长循环。
3. **米哈游风表达**：toon 卡通材质、明亮场景、发光水晶、二次元比例角色、全局打击特效。
4. **低门槛高深度**：自动战斗 + 手动开波 + 简单操作，但双路径、飞行怪、BOSS 技能与属性克制提供策略深度。

## 3. 游戏流程

```text
主菜单
  ├─ 关卡选择（3 章节 8 关卡，体力 5 点/次）
  ├─ 英雄培养（局外金币升级 2 名英雄）
  └─ 商店（购买局内技能）
战斗：准备阶段 → 开始防御 → 波次推进 → 结算
  ├─ 胜利：金币/局外金币/英雄经验/星级/首通/无伤奖励
  └─ 失败：按进度发放基础奖励与局外金币
```

## 4. 核心系统

### 4.1 战斗系统

- 怪物沿固定路径向基地水晶行进，到达后扣除基地生命值。
- 波次完成自动进入 5 秒波间倒计时，可手动提前开波并获得剩余秒数 ×2 金币。
- 双路径关卡（3002/3005/3007）奇数波走 A 路、偶数波走 B 路。
- 伤害公式：
  - 物理伤害 = 攻击力 × (1 - 护甲/(护甲+100))
  - 魔法伤害 = 攻击力 × (1 - 魔抗/(魔抗+100))
  - 最终伤害 ±10% 浮动，最低 1 点。
- 状态效果：减速、冻结、眩晕、灼烧、破甲；BOSS 免疫眩晕/冻结；飞行怪免疫地面减速。

### 4.2 防御塔系统

| 塔 | 定位 | 特性 |
|---|---|---|
| 箭塔 | 基础单体/对空 | Lv2 穿透 1 目标，Lv3 多重射击 2 目标 |
| 魔法塔 | 高伤/对亡灵 | 无视 20% 魔抗，对亡灵 +20%，Lv2 溅射，Lv3 减速 |
| 炮塔 | 群体 AOE | Lv2 破甲 30%，Lv3 灼烧 8 点/秒 |
| 冰霜塔 | 控制 | 减速/概率冻结，Lv3 每 4 秒范围冻结 |

- 升级最高 3 级，攻击间隔 = 1/攻速 + 蓄力时间；出售返还累计投入 70%。
- 目标优先级：箭/冰霜选最前方，魔法选血量最高，炮塔选最密集区域。

### 4.3 怪物与 BOSS

- 16 种怪物，按章节缩放：第二章 ×1.25，第三章 ×1.65，每 5 波属性 +8%。
- 怪物建模为头/躯干/四肢人形结构，普通小兵高度约为防御塔一半；行走采用摆臂迈腿、身体起伏的拟人步态，四足怪对角步态，飞行怪扇翅。
- BOSS：
  - 兽人队长：震地眩晕（范围 3 格，预警 1 秒）
  - 骷髅王：召唤 2 只骷髅（上限 6 只）
  - 地狱魔像：火焰冲击波（降低周围塔 50% 攻速 3 秒，全屏预警 2 秒）

### 4.4 英雄系统

| 英雄 | 定位 | 主动技能 | 解锁 |
|---|---|---|---|
| 王国游侠 | 物理远程/对空 | 穿透箭（全路径范围，对飞行 +50%） | 初始 |
| 宫廷法师 | 魔法范围/控制 | 火焰雨（3 秒灼烧 + 20% 减速） | 完成 3003 |

- 点击英雄选中 → 点击地图全图移动，自动寻路绕开防御塔，遇怪自动普攻。
- 局外升级：每级 +2% 攻击、+1% 移速，最高 30 级。

### 4.5 局外成长与运营

- 局外金币：胜利 20+星级×10+首通 50；失败 5+到达波次。
- 体力：上限 20，每次进关消耗 5，每 5 分钟回复 1。
- 商店：局内技能（箭雨/火球术/治疗波/时间缓速/金币雨），局外金币购买。
- 存档：关卡解锁、星级、英雄等级、金币、体力、技能库存本地持久化。

## 6. 美术与音频

- 美术：toon 卡通材质、蓝金 UI、发光水晶基地、二次元英雄比例、人形怪物模型。
- 特效：受击闪光、击杀粒子、开火 muzzle、范围圈、BOSS 预警圈。
- 音频：Web Audio 程序化合成（塔/怪/英雄/UI/结算/BOSS 预警）与章节自适应音乐。

## 7. 技术方案

- Three.js r160 本地化，esbuild 打包为单文件 `build/game.bundle.js`，离线双击可玩。
- 帧率无关移动（位置 += 移速 × dt），60FPS 目标；合并网格、雾效、对象池控制性能。
- 测试：Playwright + 本机 Chrome 自动回归（建塔/开波/BOSS/道具/培养/体力/商店/file 直开）。

## 9. 改进意见

1. 难度曲线缺少自动化校验：建议按“每波 DPS 需求 vs 玩家可购 DPS”做数值模拟，锁定 15%-60% 容错区间。
2. BOSS 机制偏单点：可增加阶段切换（半血转阶段）、小怪联动和二次预警，提升关底压迫感。
3. 英雄与塔的配合弱：建议给英雄增加定位选择（站桩高伤/游走支援），或加入英雄专属天赋分支。
4. 飞行单位当前只依赖箭/魔法塔，建议补充英雄对空技能提示与地图空域标识，降低信息差。
5. 局外成长与关卡难度容易失衡：建议引入关卡推荐等级/压制系统，或按英雄等级动态微调怪物体积与 AI。
6. 体力恢复曲线过线性：可增加每日任务/体力药水/好友赠送，增加回访动机。
7. 商店商品偏一次性消耗：建议加入皮肤、塔皮肤、特效皮肤、音乐包等长期内容。
8. 移动端操作仍偏重：建议增加建造暂停、范围预置位和一键补塔，减少误触。
9. 性能需在低端机实测：当前怪物模型面数增加后，需验证同屏 60+ 怪 + 全特效的帧率。
10. 缺少新手重引导：建议保留“关卡内提示”但提供可关闭选项，避免完全无教学。
