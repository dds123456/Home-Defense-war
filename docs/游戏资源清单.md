## 4. 资源管理规范

1. 命名：`类型_编号_中文名_英文名`（如 `M4001_哥布林_Goblin.png`）。
2. 程序化资源集中在 `js/td-style.js` 与各模块构造函数，便于统一换肤。
3. 引用素材放入 `assets/`，不进入线上构建（见 `.vercelignore`）。
4. 文案尽量集中，建议后续抽离为 `data/text.js`，支持多语言。
5. 音频事件名保持稳定，后续接入真实音频时按事件名替换即可。

## 5. 改进意见

1. 建议把 assets 里的角色参考图整理成“参考图-规范图-最终图”三栏，避免版本混乱。
2. 建议为每种怪物补充 2D 设定稿与 3D 模型对照表，逐项核对造型还原度。
3. 建议新增“动画状态机”文档：待机/行走/受击/死亡/技能帧数表。
4. 建议把程序化音效参数表化（频率/时长/音量），便于后续替换真实音频。
5. 建议为 UI 建立图标清单（lucide 等），替换 emoji，统一视觉语言。
6. 建议增加字体资源：中文像素/手写字体需授权确认后入库。
7. 建议建立资源命名与打包白名单脚本，防止大文件误入线上包。
8. 建议补充音乐作曲方向文档：章节 BPM、情绪曲线、循环点。
9. 建议为特效建立“最小/标准/演出”三档预算，方便性能降级。
10. 建议每两周盘点一次资源表，配合版本号记录变更。
