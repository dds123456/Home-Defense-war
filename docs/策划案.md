# 《Home Defense War》策划案

> 版本：V1.7｜更新日期：2026-08-15

## 1. 项目目标

- 上线一款 3D 米哈游风、可单机离线游玩的轻量塔防网页游戏。
- 用 8 关三章内容 + BOSS 战，形成 15-25 分钟的单局体验。
- 通过局外英雄培养、体力、商店和局内技能，建立可持续的长期循环。

## 2. 产品亮点

1. 全图自由建造与射程可视化，策略感直观。
2. 米哈游风 toon 建模、发光水晶、二次元英雄、全局打击特效。
3. 拟人化怪物动画：摆臂、迈腿、身体起伏、四足对角步态、飞行扇翅。
4. 双路径关卡、飞行怪克制、BOSS 专属技能与预警圈。
5. 双英雄 + 局外金币培养，配合体力/商店/技能形成外围成长。

## 3. 目标用户

- 核心用户：18-35 岁塔防核心玩家。
- 泛用户：二次元美术爱好者、休闲策略玩家。
- 使用场景：PC 浏览器、移动端碎片时间、离线可玩。

## 4. 核心循环

```text
选择关卡（消耗体力）→ 准备阶段建塔 → 波次防守 → 通关结算
→ 局外金币 → 英雄升级 / 商店购买局内技能 → 挑战下一关
```

## 9. 经济与运营

| 项目 | 规则 |
|---|---|
| 击杀金币 | 按怪物索引表发放，即时到账 |

## 10. 改进意见

1. 建议补充“每关推荐塔组合”，减少试错成本，提高新手完成率。
2. 建议给 BOSS 增加半血转阶段机制，形成三段式高压体验。
3. 建议英雄增加专属天赋/技能分支，强化双英雄差异。
4. 建议加入关卡星级收益：3 星可解锁扫荡或双倍奖励。
5. 建议把“首通/无伤”做成成就页，提升收集欲。
6. 建议体力系统增加每日赠送/好友赠送，平衡留存与限制。
7. 建议商店增加限时/主题商品位，形成运营抓手。
8. 建议对局外金币成长曲线做 3 轮数值校验，防止养成碾压关卡。
9. 建议补充怪物图鉴与塔图鉴，完善世界观与信息表达。
10. 建议增加局内暂停时允许“预览下一波”，强化策略准备。
