# 《Home Defense War》简要设计文档

> 版本：V1.7｜用途：团队成员与外部合作方快速了解项目

## 1. 一句话概述

《家园保卫战》是一款 3D 米哈游风单人塔防网页游戏：玩家自由建造防御塔、操控英雄、使用道具与局内技能，抵挡三章八关的怪物潮，守卫基地水晶。

## 2. 核心信息

| 项目 | 内容 |
|---|---|
| 平台 | PC / 移动端浏览器，离线可玩 |
| 引擎 | Three.js r160 |
| 语言 | JavaScript（ES Module + 单文件打包） |
| 关卡 | 3 章节 8 关卡，20-28 波 |
| 防御塔 | 4 种 × 3 级 |
| 怪物 | 16 种（含飞行/精英/BOSS） |
| 英雄 | 王国游侠、宫廷法师 |
| 核心循环 | 建塔 → 开波 → 防守 → 结算 → 局外成长 → 商店 → 再挑战 |

## 3. 玩法摘要

- 全图自由建造：除道路、基地水晶、树木、岩石外均可放置防御塔。
- 点击防御塔可查看攻击范围，升级/出售即时生效。
- 怪物沿路径移动，飞行怪仅能被箭塔/魔法塔/英雄技能攻击。
- 点击英雄选中后点击地图，英雄全图自由移动、自动攻击、主动释放技能。
- 双路径关卡奇数波 A 路、偶数波 B 路。
- BOSS 拥有专属技能与预警圈：震地眩晕、召唤骷髅、火焰冲击波。

## 4. 成长与运营

- 局内金币：建造/升级/出售、击杀奖励、波次奖励、提前开波奖励。
- 局外金币：通关结算获得，用于英雄升级与商店购买局内技能。
- 体力：上限 20，进关消耗 5，每 5 分钟恢复 1。
- 商店：箭雨、火球术、治疗波、时间缓速、金币雨等局内技能。
- 英雄等级：最高 30 级，每级 +2% 攻击、+1% 移速。

## 5. 操作方式

| 操作 | 功能 |
|---|---|
| 拖拽/滑动 | 旋转视角 |
| 滚轮/双指 | 缩放 |
| 点击空地 | 建造防御塔 |
| 点击英雄 → 点击地图 | 移动英雄 |
| 点击英雄头像 | 释放英雄技能 |
| 下一波/空格 | 提前开波 |
| P | 暂停 |

## 6. 技术要点

- 单文件打包 `build/game.bundle.js`，双击 `index.html` 即可运行。
- 帧率无关移动、合并网格、雾效、对象池，保证中低端设备流畅。
- 自动回归测试覆盖核心战斗、BOSS、道具、培养、体力、商店与离线启动。
